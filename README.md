# Mon Planning — app Android pour Octime

Application Android non officielle pour consulter son planning Octime : vues jour / semaine / mois / année, planning
d'équipe, « qui travaille ? », échanges de poste, demandes (horaire, absence, régularisation, télétravail) avec suivi
et notifications, soldes, export PDF, copie dans Google Agenda et widget d'écran d'accueil.

Ce dépôt ne contient que les versions publiées de l'app (aucun code ni aucune donnée personnelle).

## Installer

1. Sur le téléphone, ouvrir [apk/MonPlanning-0.13.0.apk](apk/MonPlanning-0.13.0.apk) puis « Download raw file ».
2. Ouvrir le fichier téléchargé ; Android demande d'autoriser l'installation depuis le navigateur : accepter.
3. Se connecter avec ses identifiants Octime habituels (ils restent sur le téléphone).

Les versions suivantes se proposent d'elles-mêmes dans l'app (Réglages › Application › Rechercher une mise à jour).
